# Cofre de Senhas — Expo SDK 57

Projeto didático mínimo com Expo Router + AsyncStorage.

## Executar

```bash
npm install
npx expo start --clear
```

Pressione `a` para Android ou `w` para Web.

Senha inicial: `1234`.

## Importante

Esta versão não inclui `@expo/ui`, `react-native-reanimated` ou `react-native-worklets`.
Esses pacotes não são necessários para o projeto e foram removidos para evitar um problema conhecido de inicialização do Expo Go com SDK 57 em Android.
